# ComfyUI-Qlip — device-agnostic deps ONLY.
#
# This file is intentionally thin: it lists only packages that are safe on ANY
# device and can NOT move your torch build. Comfy Manager auto-installs this file
# when you `comfy node install comfyui-qlip`, so it must never drag in a CUDA
# stack or a specific torch — that used to overwrite the device torch and break
# the engines.
#
# The device-specific stack (torch build, TensorRT, CuPy, qlip.core) lives in
# pyproject.toml extras and is installed by the device-aware installer:
#
#     python custom_nodes/ComfyUI-Qlip/install.py         # auto-detects device
#     # or by hand:  pip install ".[nvidia]"  /  ".[blackwell]"  /  ".[thor]"
#         --extra-index-url https://thestage.jfrog.io/artifactory/api/pypi/pypi-thestage-ai-staging/simple
#
# See README "Quick install".
